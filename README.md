## 项目概述

Wedge 是一款轻量化多功能聚合形工作台，服务于「随手打开一个文件——看懂它、改几行、理一理、比一比——然后继续干活」的场景。覆盖源码、日志、纯文本、PDF、Office 文档、图片等多种格式的查看与编辑。
本项目的目的是对专业化编辑程序的功能补充，解决编辑修改中常遇到的痛点问题，提升工作效率。不适用与专业场景开发


### 核心优势

- **零组件可用**：不装任何组件时，着色、折叠、括号配对、本地检查、格式整理、对比、检索全部可用；缺组件只把「智能提示」变轻，绝不影响查看与编辑本身
- **打开即读**：PDF / Word / Excel / PowerPoint / 图片 / 视频自动分流到只读预览，无需安装 Office、零第三方库
- **非破坏性**：写回前自动快照、编辑默认另存副本、原子写入、版本时间轴可随时还原——用户文件从不被静默覆盖
- **本地优先**：文件处理、快照库、全文索引全部在本机，不上传、不联网依赖
- **上下文还原**：布局、标签、光标、缩放、主题、快捷键、工作区随点随存、重启还原（会话恢复限 12 小时内）
- **轻得有取舍**：查看、快捷编辑、问题定位、格式整理、代码对比五件事做深；调试、构建、插件生态坚决不做

## 功能介绍

### 一、查看

- **多标签记事本体验**：编码 / BOM 自动探测、行尾识别与统一、状态栏实时显示行列 / 编码 / 行尾 / 语言 / 缩放，查找替换、转到行开箱即用
- **文档预览**：打开 **PDF** 走系统内置引擎按页渲染（连续滚动 + 翻页 + 缩放 50%–300%）；**docx / xlsx / pptx** 直读 OOXML 展示段落 / 表格 / 工作表 / 幻灯片（无需安装 Office）；图片直接预览，常见视频格式内嵌播放器；这些格式不进文本编辑器，自动落在预览视图
- **语法着色**：18 种语言内置规则 + TextMate `.tmLanguage` 扩展，细粒度分词，深浅两套主题
- **主题与配色**：深色 / 浅色 / 跟随系统（监听系统深浅色实时切换）；代码配色 5 套方案可选（入口：查看 → 代码配色）
- **检索与筛选**：查找 / 替换面板（区分大小写 · 全词 · 正则 · 结果列表）；26 种条件的行级筛选（包含 / 正则 / 通配符 / 行号区间 / 日志级别 …）；`Ctrl+Shift+F` 全局检索支持**实时扫描 / 索引检索**双模式
- **内容对比**：2–8 路并排 + 同步滚动 + 目录对比，行级着色（删红 / 增绿 / 改琥珀）+ 字符级 / 词级内联高亮 + 差异列表跳转 + 未变更长块自动折叠

### 二、编辑

- **轻改快改**：多标签编辑、格式工具栏（标题 · 列表 · B/I/S · 链接 · 表格）、字体与段落设置（**按文件记忆**）、段落增减缩进与上下移、Markdown 源码 ⇄ 预览一键切换
- **行级筛选闭环**：被筛掉的行真正折叠隐藏（行号仍是原始编号）；「在新标签打开筛选结果」得到仅含命中行的虚拟文档，改完后「**写回原文件（按行号）**」只替换命中行，**保留原 BOM / 编码 / CRLF**，写回前自动快照可一键还原
- **代码智能**：自研 LSP 客户端接入 Pyright / clangd / jdtls / TypeScript / Go / Rust 等语言服务——补全（`Ctrl+Space`）、行内预测（`Tab` 采纳）、悬停提示、诊断波浪线 + 快速修复（`Ctrl+.`）、跳转定义 / 查找引用（`F12` / `Shift+F12`）、格式化（`Shift+Alt+F`）、静态检查面板；**无语言服务时自动降级为词法补全**，核心编辑不受影响
- **网页工具**：打开 `.html` 自动分栏 WebView2 实时预览、保存即刷新，Emmet 缩写展开，局域网二维码真机预览
- **文档轻编辑**：PDF 可批注 / 改文字 / 加水印；docx / xlsx / pptx 可改段落 / 单元格 / 文本框并插图；图片可加水印
- **架构图（工具 → 生成架构图，商业解锁功能）**：未解锁时菜单项行首挂着小锁，点它直接进解锁窗口（不先让你翻目录再告诉你没授权）。选一个项目根，离线解析 `.sln` / `.csproj` 的项目清单与 `ProjectReference`；**没有 .NET 项目时改按源码里的依赖声明画**——`.py` 认 `import`（含 ComfyUI 那种 `sys.path` 平铺的裸模块名），C/C++ 认 `#include`（同名 `.h` 与 `.cpp` 合成一个编译单元），Java / Kotlin 认 `package` + `import`，Go 认 `import`（读 `go.mod` 映射目录），Rust 认 `mod` / `use`，JS / TS 认 `import` / `require`，C# / PHP 认 `using` 指向的命名空间；Java 与 Go 的方块是**包**（一个目录），其余是文件级，认不出的（`<vector>`、`java.util`、`react`）只记成外部依赖不虚构节点。生成一张**分层流程图**——一层一块、箭头即引用方向，同层文件多就排成网格，直接开在与思维导图同一个编辑区里，可拖动 / 打组 / 改色后再另存为 `.mmd`；不联网、不调模型
- **批量处理**：正则重命名（预览式映射 + 冲突检测）、批量编码转换（GBK↔UTF-8）、格式转换（MD↔HTML / CSV→XLSX），执行前出影响清单
- **输出与分享**：当前视图导出 PDF / HTML / 图片（保留语法着色）、网页整页截图、导出单文件 HTML（内联资源可离线打开）
- **外部交接**：「运行 → 用其他程序打开 ▸」现探测本机真实安装的编辑器，**带上光标行列**递给 VS Code / Cursor / JetBrains 系

### 三、存储

- **修改记忆（快照库）**：SHA-256 内容寻址快照，三重保留策略（90 天 / 200 版 / 2GB）自动清理；删除命中行、写回原文件、还原版本等动作前**一律先快照**
- **版本时间轴**：「窗口 → 版本时间轴」打开右侧栏——版本列表（时间 / 触发原因 / 大小）、内容预览、与当前文件的差异统计、「对比当前」开差异窗口、「还原此版本」（还原前再自动快照）
- **会话恢复**：退出时保存标签路径 + 光标行列 + 缩放，下次启动自动恢复（限 12 小时内）；命令行显式打开文件时以命令行为准
- **设置持久化**：主题、布局、面板显隐、快捷栏图标集、快捷键、工作区根、逐文件字体段落偏好……随点随存、重启还原；分设 `settings/`（应用级）与 `workspace/`（工作区级）
- **托盘常驻与关闭行为**：关主窗口时可选**最小化至托盘**（默认：后台继续监听与记录，托盘里一键回来）或**退出程序**——在「设置 → 外观与通用 → 关闭主窗口时」改，托盘右键菜单里也能直接切；托盘菜单还有「打开主窗口 / 显示悬浮记忆条 / 退出 Wedge」。**「文件 → 退出」与托盘里的「退出 Wedge」永远是真正退出**，不被这项设置收进托盘；悬浮条的「最小化至托盘」只收窗口、不关掉「显示悬浮条」的开关
- **快捷键可改到新工具上**：设置 → 快捷键按**分类分组**（文件 / 编辑 / 查看 / 工具 / 框图…），顶部下拉先选分类再选行；思维导图 / 框图、生成架构图这类新工具自带默认键位（`Ctrl+Alt+M` / `Ctrl+Alt+G`），只在工具栏出现的功能（三文件合并、多文件对比、导出当前文档、行筛选模式…）也一并列出，点「快捷键」列按下组合即生效；搜索认别名（搜「思维导图」能找到「新建 Mermaid 框图」）
- **全文索引**：`Ctrl+Shift+F` 索引模式走 SQLite FTS5 落库（trigram 子串语义），后台增量建索引、只索引变化的文件、已删文件自动出库，Office 文档正文同样进索引
- **用户文件安全**：编辑默认另存副本、拒绝覆盖原件；原子写入；未解锁内容自动加开发者水印（只进文件不进缓冲）
- **本地存储格式**：一切以开放格式落盘——文本保持原编码与行尾，思维导图保持标准 `.mmd`，不制造私有黑盒

## 思维导图功能

打开 `.mmd` / `.mermaid` 文件（或「文件 → 新建 Mermaid 框图」）进入**可视化思维导图 / 逻辑框图编辑器**：boardmix 式画布，全程可视化操作，不用手写源码。磁盘上仍是**标准 Mermaid flowchart 文本**——扩展信息（摆位、折叠、分组、媒体）全部写在 `%% wedge:*` 注释元数据里，**不破坏外部渲染**，用别的 Mermaid 工具照样能打开。

- **画布编辑**：双击 / `F2` 就地改字，`Tab` 加下级、`Enter` 加同级、方向键导航、`Delete` 删除，`Ctrl+Z` / `Ctrl+Y` 撤销重做（快照栈 100 步）；空白拖拽平移、`Ctrl+滚轮` **按指针位置**缩放（鼠标下的那个点不动）、`Ctrl+0` 回 100%、适应窗口；新建节点 / 注释落在鼠标处；22px 网格吸附可开关；工具条与面板不随画布缩放，任何比例下都是原尺寸
- **9 种节点形状**：起止胶囊、处理矩形、圆角、判断菱形、连接点圆、准备六边形、数据圆柱、输入输出平行四边形、子流程——与 Mermaid 语法括号一一对应；填充 / 边框 / 文字三色可配（序列化为 Mermaid 原生 `style`，外部渲染同样带色）
- **自由连线**：按住节点右侧 `⇢` 手柄拖到任意节点即建边，也支持**先选中两个模块再按 `Ctrl+L`**；支持**多父、回环、双向**；实线 / 虚线 / 粗线 × 单向 / 双向 / 无箭头可配；双击连线就地加文字；**走线可切三种**——曲线 / 直线 / 直角（电路图，拐角带 8px 圆角、自动挑不穿方块的中线），工具条 `∼` 图标一键轮换，选择写进 `%% wedge:route`
- **状态标签**：普通节点左上角可挂一枚彩色角标——内置**待开发 / 开发中 / 已完成 / 已搁置 / 注释**，也能自己起名字、挑颜色、勾虚线框；选中后按 `T` 或点悬浮条 `🏷` 打开面板，一键切换、多选批量打、还能「全部 N 个」一次标完。**标签不改变节点本身**，所以同一张图既能先把架构画出来再逐个改成「开发中 / 已完成」，也能对着已有代码生成架构图后直接标进度。落盘为 `%% wedge:tag <id> <文字> [#色] [dash]`，外部 Mermaid 打开仍是普通节点（旧文件的 `%% wedge:kind` 会读成同名标签）
- **注释卡片**：`N` 加一张带「注释」标签的卡片，生成架构图后补说明用
- **画布键位可改**：`设置 → 快捷键 → 框图`（单独存 `settings\mindmap-keys.json`）：新建下级 / 同级、连线、注释、状态标签、重命名、删除、折叠、打组、撤销、重做、适应窗口 13 个动作都能换键，改完当前画布立即生效
- **四向排版**：→ 思维导图、↓ 组织架构图、← ↑ 同理；自动排版 + 手动摆位（`%% wedge:pos` 落盘）+「整理布局」一键回自动
- **折叠与打组**：`⊟` 手柄或 `F` 折叠子树（右上角 `+N` 徽标，折叠部分不渲染不占位）；`Ctrl+G` 打组，支持多选 / 框选——组有三种形态：打组未收 = 包裹框 + 标题条，打组收起 = 28px 标题条，子图 = 固定卡片（双击进入）；**双击标题条就地改名**（失焦即存），双击框体展开 / 收起
- **挂资料**：节点可挂**文档引用**（`📄` 标签一点即在主窗口打开并定位到项目树），也可**内嵌图片 / 视频 / 音频**（缩略图 / 控制条 / 播放器直接在节点里）
- **兼容与回退**：遇到时序图等非 flowchart、或多父环状等超出现有可视化范围的图，自动退化为 mermaid 只读渲染 + 顶部横幅说明；新建模板即带判断分支与回环的代码流程图，打开就能改
